# AgentAwake

Keep Codex and other local agents running with your MacBook’s lid closed.

**[Download for Apple Silicon](https://github.com/devnjw/agent-awake/releases/download/v0.3.1/AgentAwake-0.3.1-arm64.dmg)** · [한국어](README.ko.md)

macOS 14+ · Apple Silicon (M-series)

## Get started

1. Open the DMG and drag **AgentAwake.app** to **Applications**.
2. Launch it and click the **⚡** in your menu bar.
3. Turn on **Keep awake**. A charger is required by default.

## Options · ⋯

| Option | What it does |
| --- | --- |
| **Only when plugged in** | Uncheck to allow battery use. Your choice is saved. |
| **Turn off displays** | Sleep all screens. Keyboard, mouse, or trackpad input wakes them. |
| **Stop after** | Until stopped, or 1 / 2 / 4 / 8 hours. |
| **Launch at login** | Open at sign-in. Keep awake starts off. |

Early preview: Developer ID signed, not notarized ([first-launch help](https://support.apple.com/102445)). Lid control uses a private macOS API; test a short session on your Mac first. Use a ventilated surface.
