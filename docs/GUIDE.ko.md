# 도움말·문제 해결

[README로 돌아가기](../README.ko.md) · [English](GUIDE.md)

## 전원과 종료 시간

**Only when plugged in**은 기본으로 체크되어 있습니다. 충전기를 빼면 켜 둔
세션이 일시 정지하고, 다시 연결하면 재개합니다. 해제하면 배터리에서도 유지합니다.
전원 조건은 저장되며, 변경해도 종료 시간은 그대로입니다.

충전기 연결 여부로 판단하므로 배터리가 100%이거나 최적화 충전으로 충전이
멈춰 있어도 동작합니다. 배터리 허용 모드는 배터리를 소모하며, 배터리 소진으로
인한 잠자기·종료를 막지는 못합니다.

macOS가 심각한 온도 상태를 보고하면 일시 정지했다가 온도가 안정되면 재개합니다.
앱을 종료하거나 설정 시간이 끝나면 유지 요청을 해제합니다. 로그인 실행을 포함해
앱은 항상 Keep awake가 꺼진 상태로 시작합니다. 실행 중 **Stop after**를 바꾸면
그 시점부터 새로 시간을 계산하며, 남은 시간도 설정 메뉴에 표시됩니다.

## 화면 끄기

**Turn off displays**는 외부 모니터를 포함한 모든 화면을 끕니다.
키보드·마우스·트랙패드 입력으로 다시 켜집니다. Keep awake 상태는 바뀌지 않으므로,
화면을 끈 동안에도 작업을 이어가려면 켜 두세요. 기존 macOS 잠금·암호 설정은 그대로입니다.

## 최초 실행

배포 파일은 Developer ID 서명을 포함하지만 Apple 공증은 없습니다.
macOS가 실행을 막으면 [Apple의 앱별 ‘Open Anyway’ 안내](https://support.apple.com/102445)를
따르세요. 조직에서 관리하는 Mac은 이를 제한할 수 있습니다.
Gatekeeper 전체를 비활성화하지 마세요.

ZIP 파일과 SHA256 체크섬은 [릴리스 페이지](https://github.com/devnjw/agent-awake/releases/tag/v0.2.0)에서도 제공합니다.

## 내 Mac에서 확인하기

덮개 제어는 비공개 macOS API를 사용하며, Mac 모델·외부 화면 구성·macOS 업데이트에
따라 결과가 달라질 수 있습니다. 충전기를 연결하고 Keep awake를 켠 뒤, 진행 상태를
기록하는 간단한 로컬 작업을 실행하세요. 덮개를 30초 닫았다 열어 작업이 계속됐는지
확인합니다. 그다음 Keep awake를 끄고 평소처럼 잠자기가 동작하는지 확인하세요.
긴 작업 전에 실제 사용할 전원 조건과 모니터 구성에서도 확인하세요.

통풍되는 단단한 표면에서 사용하고, 깨어 있는 MacBook을 가방에 넣지 마세요.
다른 덮개·절전 제어 앱과 동시에 사용하지 않는 편이 좋습니다.
네트워크 단절, 에이전트의 승인 대기, 다른 앱 자체의 오류는 직접 확인해야 합니다.

## 문제 해결

- **토글이 켜져 있는데 작업이 멈춰요:** 전원 조건과 일시 정지 안내를 확인하고,
  위의 짧은 덮개 시험을 해보세요.
- **Monitor 오류가 나요:** 앱을 종료하고 다시 여세요. UI와 감시 프로세스를 동시에
  강제 종료한 뒤 잠자기가 이상하면 Mac을 재시동하세요.

영구 pmset 설정은 수정하지 않습니다. 서버·분석 수집·에이전트 내용 접근·관리자 서비스·입력 감시는 없습니다.

## 앱 삭제

**Launch at login**을 끄고 앱을 종료한 뒤 Applications의 AgentAwake를 휴지통으로
옮깁니다. 종료 후에는 ~/Library/Application Support/AgentAwake의 잠금 파일
디렉토리도 지워도 됩니다. 전원 조건은 앱의 로컬 환경설정에 저장됩니다.
